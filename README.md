## Experience supported by these projects

Lahda, IQBox and Deinkow were previously deployed and tested. Lahda was previously published on Google Play and is currently unavailable there. Historical deployment is documented separately from current release verification.

Each repository explains its architecture, setup, synthetic demonstration, checks and limitations in English and Arabic. BACUA is a frontend with mock authentication and assistant responses; FH-School uses synthetic school records. No audience, revenue or prediction-accuracy figures are invented.
