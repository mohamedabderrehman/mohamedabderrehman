# محمد عبد الرحمن

**مطور ويب وموبايل متكامل**

أبني تطبيقات لمسارات عمل متكاملة في التجارة والتوصيل ومشاركة الملفات والتعاون مع العملاء والتعليم والبحث، مع واجهات عربية RTL وخوادم TypeScript وبوابات PHP وقواعد علائقية.

[المعرض ودراسات المشاريع](https://mohamed-abderrehmane-portfolio.hillock-factual9mupt.chatgpt.site/ar/) · [English](README.md)

## أعمال مختارة

| المشروع | الخبرة التي يعرضها |
|---|---|
| [Lahda](https://github.com/mohamedabderrehman/lahda) | React Native وNestJS وPostgreSQL؛ مسارات العميل والتاجر والسائق والمدير والنقد وترحيلات Prisma |
| [IQBox](https://github.com/mohamedabderrehman/iqbox) | Kotlin وCompose ومشاركة أندرويد ورفع Express وصفحات المشاركة والإدارة |
| [Deinkow](https://github.com/mohamedabderrehman/deinkow) | موقع استوديو عربي وبوابة PHP وغرف العمل والرسائل والمرفقات الخاصة |
| [MisterX](https://github.com/mohamedabderrehman/misterx-search) | بحث PHP وOpenSearch وصفحات النتائج ومخبأ Redis الاختياري والوظائف الخلفية ببيانات اصطناعية مصرح بها |
| [BACUA](https://github.com/mohamedabderrehman/bacua) | واجهة تعليم Expo وReact Native ودعم RTL وحفظ الحالة ومساعد بث محاكى |
| [Local Text Search](https://github.com/mohamedabderrehman/local-text-search) | وظائف Flask ومسح mmap وعزل النتائج ومسار Cython اختياري |

## الخبرة الموثقة

نُشرت واختُبرت Lahda وIQBox وDeinkow سابقاً. نُشر تطبيق Lahda لتوصيل الطعام والبقالة على Google Play. يميز التوثيق النشر السابق من التحقق الحالي.

يوضح كل مستودع البنية والإعداد والعرض الاصطناعي والفحوص والحدود باللغتين. BACUA واجهة بمصادقة وإجابات محاكاة، وتستخدم FH-School سجلات مدرسة اصطناعية. لا ندعي أرقام جمهور أو إيرادات أو دقة تنبؤ غير مقاسة.
